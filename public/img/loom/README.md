# Loom posters

Generated by `npm run gen:loom-posters`, which boots the real rig in a
headless browser and renders one frame. Nothing approximates the engine,
so a poster cannot drift from what the live stage draws.

**This directory is empty on purpose.** The generator refuses to run
without the site's webfonts. It must be run somewhere that can reach
`fonts.googleapis.com` — a normal dev machine — and the output committed.
It is not a build step: it needs a browser and takes seconds per product.

## Why the generator refuses

A canvas does not throw when a webfont is missing; it silently draws in a
fallback. `document.fonts.check()` does not help — with the stylesheet
request blocked it still returns `true`, because a fallback family
satisfies the query. So the generator measures instead: two font stacks
naming the same fallback produce identical advance widths only when the
real face is absent.

This matters most for the name bib, which is machine embroidery in a
script face. Baked in a fallback serif it reads as *print*, not stitching
— a quietly wrong product photo shown to every visitor whose device
cannot run the 3D.

The blanket is guarded the same way. A fallback serif still draws correct
Armenian letterforms, but it is not the site's typeface, and a poster
should match the stage it stands in for.
